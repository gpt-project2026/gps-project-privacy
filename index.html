GPS PROJECT

GPS PROJECT は、運営者本人が所有する YouTube チャンネルへ動画を投稿し、投稿結果と視聴統計を確認するための、個人利用のツールです。一般公開のサービスではありません。

プライバシーポリシー

1. 取得する情報

運営者本人の Google アカウントで認可を受け、次の範囲の YouTube API にアクセスします。

  • 自分のチャンネルへの動画のアップロードと、公開設定・サムネイルの管理
  • 自分のチャンネルと動画の情報の閲覧
  • 自分のチャンネルの分析(YouTube Analytics)の閲覧

2. 情報の利用目的

上記の情報は、運営者本人のチャンネルへの動画投稿と、投稿結果の確認のためだけに使います。

3. 第三者への提供

取得した情報を、第三者へ提供・販売・共有することはありません。広告にも使いません。

4. 保管

認可情報(トークン)は、運営者本人のコンピューター内にのみ保管します。外部のサーバーへは送信しません。

5. 削除と取り消し

アクセス権は、Google アカウントの「サードパーティのアクセス」からいつでも取り消せます。

6. YouTube API サービス

本ツールは YouTube API サービスを使用します。利用者は YouTube 利用規約 に同意したものとみなされます。Google のデータの扱いは、Google プライバシーポリシー に従います。

Privacy Policy (English)
